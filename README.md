# elections

Materials for teaching and research on Israeli elections, published via GitHub Pages
at https://pedahzur.github.io/elections/

## Contents

- **election-aggregator/** — An Israel election poll aggregator drawing on data.gov.il and Wikipedia.
- **meetings/**, **posts/**, **docs/** — A Quarto course blog (landing page, meeting notes, syllabus, and bibliography).

## Build

This is a Quarto site. Rendered output is served from `docs/` via GitHub Pages.

## Status & reuse

Actively maintained for teaching. Please check the license before reuse and open an issue for corrections.
